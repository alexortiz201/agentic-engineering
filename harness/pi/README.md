# Canonical selective Pi source

This directory is the sole authored source for the five selective Pi packages, `settings.example.json` and `accepted.json`. **Prepared source-transition candidate:** Main must verify Air's selective ownership handoff before integrating this change into shared sources. This branch does not authorize deployment, synchronization or live edits.

## Supported source workflow

Edit the selected package or portable seed here directly; review changes and run the [CLI checks](../../cli/AGENTS.md#paved-road). `cli/tests/sources.test.ts` validates the exact package inventory, accepted metadata/seed contract and source-only Stow lifecycle without root `pi/`. There is no generation step: `setup/stage-pi.mjs` is retired because it could overwrite live Mini resources. Never regenerate these files from legacy copies.

`accepted.json` is authored acceptance metadata, not an installer lock or generated output. `runtime` and `todo` retain the accepted official managed Pi 1.5.2 / exact Todo 1.1.0 pins. `baseline` identifies the historical Git resource blobs used by the read-only five-link inspector; it is not the current authored-source revision. Keep this baseline stable for this byte-preserving transition. Future resource/pin changes require their own review and acceptance, including inspector-baseline implications; do not silently repin or derive metadata from legacy locks.

The setup CLI installs **only selected** packages: instructions, theme, Workbench Skill, Study Skill, composer. Never Stow this directory wholesale. Defaults and Todos are independent operations; the seed is not local settings. Herdr's reporter remains locally generated by Herdr. These sources neither install nor wrap the executable. Settings/auth/sessions/notes remain local.

Historical path statements remain evidence, not instructions to repeat accepted migrations.

Root/installer/dotfiles retirement requires named-consumer disposition and separate approval.
